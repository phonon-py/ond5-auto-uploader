# Pond5 自動アップローダー

Seleniumを使用してPond5に楽曲を自動アップロードするツール

## 📋 機能

- **自動ログイン**: Pond5への自動ログイン
- **バッチアップロード**: 複数ファイルの一括アップロード
- **CSV連携**: 差分CSVからアップロード対象を自動取得
- **進捗ログ**: 詳細なログ出力
- **エラーハンドリング**: 失敗したファイルの追跡

## 🚀 セットアップ

### 1. 必要なパッケージをインストール

```bash
pip install selenium webdriver-manager
```

### 2. 設定ファイルを編集

`config.json` を開いて以下を設定:

```json
{
  "email": "your_pond5_email@example.com",
  "password": "your_password",
  "music_folder": "C:/Music/WAV_Files",
  "csv_file": "pond5_upload_diff_316songs.csv",
  "headless": false,
  "upload_batch_size": 20,
  "wait_between_uploads": 2,
  "timeout": 60
}
```

| 項目 | 説明 |
|------|------|
| `email` | Pond5のログインメールアドレス |
| `password` | Pond5のパスワード |
| `music_folder` | WAVファイルが保存されているフォルダ |
| `csv_file` | アップロード対象の差分CSVファイル |
| `headless` | `true`=ブラウザ非表示、`false`=表示 |
| `upload_batch_size` | 1バッチあたりのアップロード数 |
| `wait_between_uploads` | アップロード間の待機秒数 |
| `timeout` | タイムアウト秒数 |

### 3. 差分CSVを配置

Claudeが生成した `pond5_upload_diff_316songs.csv` をスクリプトと同じフォルダに配置

## 📖 使用方法

### 基本的な使い方

```bash
python pond5_auto_uploader.py
```

### オプション

```bash
# 設定ファイルを指定
python pond5_auto_uploader.py --config my_config.json

# Pond5用CSVを生成のみ
python pond5_auto_uploader.py --generate-csv --input-csv diff.csv --output-csv pond5_ready.csv
```

## ⚠️ 注意事項

### セキュリティ
- `config.json`にパスワードが平文で保存されます
- `.gitignore`に追加してバージョン管理から除外してください

### Pond5の制限
- 大量アップロードはレート制限される可能性があります
- バッチサイズとインターバルを調整してください
- 審査に数日かかる場合があります

### トラブルシューティング

| 問題 | 解決策 |
|------|--------|
| ログインできない | メール/パスワードを確認、2FA無効化 |
| ファイルが見つからない | `music_folder`のパスを確認 |
| タイムアウト | `timeout`を増やす |
| アップロードが遅い | `wait_between_uploads`を減らす |

## 🔧 カスタマイズ

### ファイルアップロードのみ（メタデータは後で手動）

```python
uploader = Pond5Uploader("config.json")
uploader.driver = uploader._setup_driver()
uploader.login()
uploader.upload_files(["/path/to/file1.wav", "/path/to/file2.wav"])
```

### CSVメタデータ適用のみ

```python
uploader = Pond5Uploader("config.json")
uploader.driver = uploader._setup_driver()
uploader.login()
uploader.apply_csv_metadata("pond5_metadata.csv")
```
